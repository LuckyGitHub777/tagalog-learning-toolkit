# Security Policy

## Supported release

Security fixes are applied to the latest public release on the `main` branch. The current software baseline is **4.0.0**.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository:

`https://github.com/LuckyGitHub777/tagalog-learning-toolkit/security/advisories/new`

Include:

- affected page or file;
- reproduction steps;
- expected and observed behavior;
- browser or device details;
- potential impact;
- a minimal proof of concept when safe.

Do not post an exploitable vulnerability, credential, private learner data, or sensitive recording in a public issue before remediation is available.

The maintainer will acknowledge a credible report as soon as practical and coordinate disclosure after a fix is deployed.
