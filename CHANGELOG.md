# Changelog

## 2.0.0 - 2026-07-13

- Rebuilt the package as a neutral, public Tagalog learning toolkit.
- Removed organization-specific branding, logos, and personal examples.
- Added an installable offline-ready progressive web app.
- Added adaptive daily review and phrase mastery records.
- Added searchable lesson content and category filtering.
- Added local speaking playback and session-only voice recording.
- Added progress export and import.
- Added editable sentence builders.
- Added keyboard-complete tab navigation and appearance modes.
- Added a Python validation, serving, and terminal-study companion.
- Added lesson schema, GitHub Actions validation, expanded tests, and neutral PDFs.
