# Language Guide

Tagalog varies by context, register, region, and speaker community. Tagalog Academy uses a consistent beginner standard while clearly labeling common, formal, native, descriptive, and regional alternatives.

## Editorial rules

- Teach one canonical form per learning record.
- Represent meaningful alternatives as separate records.
- Give every practice prompt exactly one expected teaching record.
- Keep accepted recall forms explicit and normalized.
- Label register, aspect, and usage where context changes meaning.
- Prefer complete, useful phrases over isolated terminology.
- Explain completed actions as completed forms rather than dictionary infinitives.

## Current conventions

- Display `Na-stress ako.` and accept documented everyday alternatives.
- Display `Kwarto` and accept `kuwarto` in recall.
- Use standard assimilated number forms such as `labindalawa` and `labintatlo`.
- Distinguish `dalandan` as a citrus fruit from `kahel` as a color term.
- Label morning-routine sentences as completed actions.
- Distinguish everyday and formal family terms in exercises.

## Pronunciation

Browser speech depends on the voices installed on the device. The interface identifies when a Filipino voice is unavailable. Playback supports listening and repetition; learners should compare pronunciation with fluent speakers and high-quality recorded sources.

## Corrections

Language corrections should identify the exact lesson text, proposed wording, usage context, and supporting evidence. The repository provides a dedicated language-correction issue form.
