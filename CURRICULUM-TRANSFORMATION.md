# Curriculum Transformation

## Source inventory

A private curriculum source map was audited during transformation. Its source URLs are intentionally not shipped in the public repository because it includes class-administration and submission links. The audited categories were:

- Four memorization lists
- Four homework assignments
- Four weekly challenges
- Four songs
- Four quizzes
- Six class recordings
- Six slide decks
- Four homework-submission forms
- One live Zoom link

## Transformation decisions

| Source type | Public treatment |
|---|---|
| Memorization lists | Convert into structured vocabulary and retrieval practice |
| Homework | Convert into native builders, typing, quizzes, and missions |
| Weekly challenges | Neutralize branding and convert into outcome-based missions |
| Songs | Link as optional third-party listening resources |
| Quizzes | Replace external forms with native private quizzes |
| Class recordings | Use as curriculum reference; do not automatically publish or embed |
| Slide decks | Extract aligned concepts; do not mirror branded decks |
| Submission forms | Exclude from public product |
| Zoom link | Exclude from public product |

## Current implementation

### Week 1

Introductions, greetings, feelings, school, work, family, adjectives, polite yes/no.

### Week 2

Colors, color linkers, food, drinks, preferences, likes, dislikes.

### Week 3

Household objects, places at home, `nasaan`, `nasa`, `ang`, `si`, simple possession.

### Week 4

Numbers, number linkers, relationships, fruits, prices, quantities, market dialogue.

## Weak links corrected

- Week 4 was broader than the workbook label suggested.
- A Lesson 6 slide deck was labeled for kids, not adults.
- Live-class and submission links were mixed into the learning workbook.
- External quizzes would expose learners to a separate platform and data flow.
- Branded challenges instructed learners to post publicly.
- One Week 4 quantity prompt was grammatically malformed.

## Operating rule

The source workbook is an intake map, not the public user experience.

Every source must pass:

```text
Access
→ Rights
→ Accuracy
→ Adult relevance
→ Privacy
→ Learning objective
→ Public implementation
```
