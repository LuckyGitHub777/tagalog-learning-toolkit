# Publishing Checklist

## Automated Gate

- [ ] Run `python scripts/validate_repo.py`.
- [ ] Run `python -m unittest discover -s tests -v`.
- [ ] Run `node --check assets/js/app.js`.
- [ ] Confirm `MANIFEST.sha256` was regenerated by the validator.

## Human Content Gate

- [ ] Obtain review from a qualified Tagalog educator or fluent reviewer.
- [ ] Confirm accepted-answer variants and spelling rules.
- [ ] Confirm course naming: Tagalog, Filipino, or both.
- [ ] Confirm examples are inclusive and appropriate for the intended audience.
- [ ] Confirm any new audio has contributor permission and attribution.

## Deployed Experience Gate

- [ ] Test the public GitHub Pages URL on a desktop browser.
- [ ] Test the public URL on at least one Android or iOS device.
- [ ] Confirm the service worker installs and the site reopens offline.
- [ ] Confirm app installation where supported.
- [ ] Confirm browser speech playback.
- [ ] Confirm microphone recording and playback on a real device.
- [ ] Confirm progress export, import, and reset.
- [ ] Confirm all three PDFs open from the public URL.
- [ ] Test keyboard navigation and visible focus.
- [ ] Test print output for the Apply section.

## Release Language

Publish as a **Week 1 beta** until real learners and human language reviewers provide proof. Do not claim complete fluency training, certified pronunciation assessment, or market leadership without evidence.
